## О проекте
Одностраничный лендинг с переключением разделов:
Главная, О нас, Услуги, Контакты.

## Технологии
- HTML5
- CSS3 (Grid, Flexbox, CSS-переменные, media-queries)
- JavaScript (ES6+)

## Что реализовано
- Адаптивная вёрстка под телефон, планшет, ПК
- Переключение тёмной и светлой темы (сохраняется в localStorage)
- Плавные анимации появления при прокрутке (IntersectionObserver)
- Проверка полей формы перед отправкой (валидация)
- Плавный переход между разделами без перезагрузки страницы

## Как запустить
Открыть файл `index.html` в любом браузере.

- Как использовать `localStorage` для сохранения настроек
- Как работает `IntersectionObserver` для анимаций
- Как делать валидацию формы на JavaScript
